# وردي PDF — محوّل Word إلى PDF

تطبيق ويب أنيق باللون الوردي يحوّل ملفات Word (`.docx` `.doc` `.rtf` `.odt`) إلى PDF **بدون أي تغيير في المحتوى أو التنسيق**: الخطوط، الجداول، الصور، الهوامش، الترقيم، الرؤوس والتذييلات، والنص العربي من اليمين لليسار — تماماً كما يفعل "حفظ كـ PDF" في Microsoft Word.

## لماذا التحويل احترافي؟
التحويل داخل المتصفح (مكتبات JavaScript) يعيد رسم المستند بشكل تقريبي فيضيّع التنسيق. لذلك يستخدم التطبيق محرّك **ConvertAPI** المبني على تقنيات Microsoft Office، عبر دالة خادم على Netlify تُخفي مفتاحك السري.

## خطوات النشر على Netlify (5 دقائق)

1. **احصل على مفتاح مجاني** من [convertapi.com](https://www.convertapi.com/a/signup) ← بعد التسجيل افتح لوحة التحكم وانسخ **API Token** (الحساب المجاني فيه رصيد تحويلات تجريبي، وبعدها خطط مدفوعة).
2. **ارفع المشروع إلى Netlify** بإحدى الطريقتين:
   - اسحب المجلد كاملاً إلى [app.netlify.com/drop](https://app.netlify.com/drop) *(ملاحظة: السحب المباشر لا يبني الدوال في بعض الحسابات؛ الأفضل الطريقة الثانية)*.
   - أو ارفع المجلد إلى مستودع GitHub ثم في Netlify: **Add new site ← Import an existing project** واختر المستودع. الإعدادات تُقرأ تلقائياً من `netlify.toml`.
   - أو عبر سطر الأوامر: `npm i -g netlify-cli` ثم `netlify deploy --prod` داخل المجلد.
3. **أضف المفتاح**: في Netlify افتح **Site configuration ← Environment variables ← Add a variable**
   - الاسم: `CONVERTAPI_SECRET`
   - القيمة: المفتاح الذي نسخته
4. أعد النشر (**Deploys ← Trigger deploy**) وجرّب التطبيق.

## هيكل المشروع
```
word-to-pdf/
├─ index.html                   ← الواجهة (عربية، وردية، سحب وإفلات، معاينة وتنزيل)
├─ netlify/functions/convert.mjs ← دالة التحويل (المفتاح لا يظهر للمتصفح)
├─ netlify.toml                 ← إعدادات Netlify
└─ package.json
```

## كيف يعمل
1. المتصفح يرفع الملف مباشرة إلى خادم التحويل (فلا يوجد حد 6MB الخاص بدوال Netlify).
2. الدالة `/api/convert` تبدأ تحويلاً غير متزامن بمفتاحك، ثم تتابع حالته (فلا تتجاوز مهلة الـ10 ثوانٍ).
3. يظهر ملف PDF للمعاينة داخل الصفحة مع زر تنزيل.

الملفات تُحذف تلقائياً من خوادم التحويل بعد 3 ساعات كحد أقصى.

## تجربة محلية
```bash
npm i -g netlify-cli
export CONVERTAPI_SECRET=مفتاحك
netlify dev
```
ثم افتح http://localhost:8888
